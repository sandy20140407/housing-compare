# housing-compare

新加坡私宅 **买房 vs 租房** 对比计算器，覆盖新房楼花（BUC）、二手房和 TOP 时卖出三种场景。

在线版本：<https://sandy20140407.github.io/housing-compare/>

## 功能

- **按月模拟**：楼花按标准进度款节点逐步放贷，建设期月供按已放款额计算，不再简化成 0。
- **税费**：
  - BSD 按分级税率计算。
  - ABSD 按身份（SC / PR / 外国人）和第几套计算。
  - SSD 采用 2025-07-04 起的 4 年持有期。
- **CPF**：
  - OA 用于首付和月供，卖房时连本带 2.5% 应计利息退回。
  - 租房方案的 OA 留在账户里继续生息。
- **公平比较**：
  - 两个方案每月总预算相同，花得少的一方把差额拿去投资。
  - 签约时的首付和税费，在租房方案里全部拿去投资。
- **变现口径**：期末净资产扣除剩余贷款、未付进度款、中介费、律师费和 SSD。
- **其他**：
  - 30 年净资产走势图，标出反超年份。
  - 纯房产投资 IRR。
  - TDSR 压力测试。
- **参数存进 URL**：可以直接分享具体方案。

## 计算口径

核心逻辑在 [`src/lib/calc.ts`](src/lib/calc.ts)，是纯函数、无 UI 依赖。政策常量集中在 [`src/lib/rules.ts`](src/lib/rules.ts)，政策变动时只需改这一个文件。

| 项目 | 规则 | 依据 |
|---|---|---|
| BSD | 1% / 2% / 3% / 4% / 5% / 6%，分段上限 180k / 360k / 1M / 1.5M / 3M | IRAS 住宅 BSD |
| ABSD | SC 0/20/30%，PR 5/30/35%，外国人 60% | 2023-04-27 起 |
| SSD | 持有 ≤1/2/3/4 年：16/12/8/4%，楼花从签约起算 | MOF，2025-07-04 起购入 |
| LTV | 首套 75%，至少 5% 现金首付 | MAS |
| TDSR | 55%，压力利率 4% | MAS |
| CPF OA | 2.5% | CPF Board |

### 简化处理

- BSD、ABSD 按现金支付。BSD 实际可以用 CPF 报销，这里按保守口径处理。
- 进度款各节点的时间按建设期均匀估计，CSC 设在 TOP 后 12 个月。
- 「持有 N 年」视为满 N 年后卖出。如果恰好在周年当天卖出，IRAS 仍按上一档计 SSD。
- 地契衰减使用 Bala's Table 形状的近似曲线。
- 以下项目未计入：
  - 装修费
  - 租房中介费
  - 出租收入
  - 利率波动

**仅供参考，不构成财务或法律建议。**

## 开发

```bash
npm install
npm run dev        # 本地开发
npm test           # 计算引擎单测（vitest）
npm run build      # 类型检查 + 生产构建
```

推送到 `main` 后，GitHub Actions 会跑测试并部署到 GitHub Pages。首次使用前，需要在仓库的 **Settings → Pages → Source** 中选择 **GitHub Actions**。

## 历史

最初版本是一个单文件 Claude artifact，见首个提交。重构时修正了以下问题：

- TOP 卖出收益没有扣除贷款本金，导致收益被大幅高估。
- SSD 仍按旧的 3 年持有期计算。
- BSD 写死为 4%。
- 建设期买方月供和租房成本记为 0。
- 租房方的 CPF 余额没有计入。
